# SOP-044: CNC Cutting Tool Life Management & Quality Gates
## 1. Scope and Objective
This standard operating procedure governs carbide turning insert usage and wear limits on CNC Lathes CNC-01 through CNC-06.

## 2. Mandatory Thresholds
- **Reference Inspection Interval:** Visually inspect cutting insert flank wear every 300 cycles.
- **Maximum Wear Threshold:** Cutting tool usage must not exceed 800 cycles for AISI 1045 carbon steel.
- **Vibration Alarm Limit:** Machine vibration exceeding 3.5 mm/s requires immediate tool wear inspection.

## 3. Tool Replacement Protocol
1. Stop spindle and clear chips.
2. Remove turning insert and inspect nose radius under 20x shop microscope.
3. Index insert to fresh cutting tip or replace with certified Kennametal CNMG 120408.
4. Re-zero controller tool wear offset register.
