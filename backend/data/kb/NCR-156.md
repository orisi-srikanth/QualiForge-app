# Nonconformance Report: NCR-156
- **Title:** Missing milled keyway pocket on PS-2026-101 shaft due to CNC milling sub-routine call omission
- **Defect Type:** missing_feature
- **Defect Family:** machining_omission
- **Part Number:** PS-2026-101
- **Machine:** CNC-02
- **Date:** 2026-10-05
- **Data Provenance:** synthetic_illustrative

## Description
Visual inspection detected complete absence of milled keyway slot on central body section of precision shaft. Surface remained unmachined cylindrical blank profile.

## Confirmed Root Cause
NC part program edit by night shift operator inadvertently commented out sub-program call M98 P2001 (keyway milling cycle) following tool offset adjustment.

## Resolution & Corrective Action
Locked CNC controller program memory with supervisor password, installed macro verification interlock checking tool cycle completion before part unclamp, and restored validated NC code.

## Containment Action
Quarantined 42 parts; routed through secondary milling fixture to machine required keyway.
