# Standard Operating Procedure: Visual Inspection and AI Decision Review
- **Document ID:** SOP-055
- **Title:** Visual Defect Review, Model Confidence Thresholds, and Disposition Protocol
- **Version:** 3.0.0
- **Effective Date:** 2026-10-11
- **Data Provenance:** synthetic_illustrative

## 1. Purpose and Scope
This procedure specifies how automated computer vision inspection predictions (MobileNetV3-Small transfer learning classifier with Grad-CAM localization) are evaluated, confirmed, or escalated by Quality Engineers. Applies to machined precision shaft inspection (Part PS-2026-101) and associated components.

## 2. Standard Defect Taxonomy for Machined Shafts
All automated visual quality detections must classify into the six established classes:
1. **`no_defect` (Conforming):** Pristine machined surface, correctly ground journals, properly milled keyway pocket, and correctly positioned retaining collar.
2. **`surface_scratch`:** Longitudinal or oblique tool scoring, chatter marks, or abrasive swarf dragging along the cylindrical journal surface.
3. **`dent`:** Localized impact craters, handling gouges, or drop indentations on outer cylindrical diameters.
4. **`crack`:** Hairline stress fractures or thermal quench/grinding micro-cracks propagating across the cylindrical body or shoulder fillets.
5. **`missing_feature`:** Workpiece missing a required milled keyway pocket or missing a circlip groove due to program sub-routine omissions.
6. **`incorrect_assembly`:** Retaining collar or spacer ring positioned at incorrect axial coordinates or mounted with excessive tilt/skew.

## 3. Confidence Thresholds and Operational Routing
1. **Conforming Classification (`no_defect`):**
   - Predicted class is `no_defect` with model confidence >= 0.70.
   - Component automatically marked conforming for visual criteria and released to downstream assembly.
2. **Confident Defect Identification (>= 0.70 Confidence):**
   - Model identifies defect class (`surface_scratch`, `dent`, `crack`, `missing_feature`, `incorrect_assembly`).
   - Generates localized bounding box ROI and Grad-CAM activation heatmap overlay.
   - Component flagged for secondary visual engineering review on the inspection console.
3. **Uncertain Prediction (< 0.70 Confidence):**
   - Model flags result as `uncertain`.
   - Automatic line diverter routes component to the Human-in-the-Loop Quality Station for manual gauge check.
4. **Out-of-Domain Classification (`out_of_domain`):**
   - If optical profile matches none of the trained classes or categories, system outputs `out_of_domain`.
   - Component held for manual metrology bench verification.

## 4. Human Quality Engineer Confirmation Protocol
Quality Engineers must review the multi-panel console display (Raw Image, Grad-CAM Overlay, Bounding Box ROI):
- **Confirm Defect:** If physical inspection verifies visible discontinuity matching model ROI, engineer clicks `Confirm Defect`, generating an electronic Nonconformance Record (NCR).
- **Reject (False Positive):** If benign surface feature (e.g. permissible reflection gradient, washable coolant film) triggered a false alarm, engineer records rejection rationale and releases component.

## 5. Honest Disclosure & Limitations
- **Synthetic Training Origin:** The vision model is trained on synthetic shaft images generated by our procedural generation script. Metrics are optimistic compared to real factory images.
- **Factory Calibration:** The model has not been validated on physical factory shaft photos and is NOT production-grade without physical factory calibration.
- **Uncalibrated Confidence:** Model outputs represent uncalibrated softmax confidences, not true Bayesian posterior probabilities.
- **Human Oversight:** Automated inspection serves as decision support only; human engineering disposition remains strictly mandatory.
